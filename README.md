# 不存在的山城音游社 – 網站

靜態單頁網站（無任何框架、無外部依賴），直接雙擊 `index.html` 即可在瀏覽器開啟。

## 檔案結構

- `index.html` – 頁面結構與內容
- `styles.css` – 樣式（深色霓虹音游風）
- `script.js` – 互動（背景音符、滾動動畫、數字計數、Combo 彩蛋、意向表）

## 小彩蛋

在頁面空白處點擊，會出現音游判定文字與連擊計數（COMBO）。連擊會在 1.6 秒內無點擊後歸零。

## 預覽模式

在網址後加上 `?shot`（例如 `index.html?shot`）可立即顯示全部內容並停用動畫，方便截圖或快速檢視整頁排版。
